1. **Unit Testing**: Testing individual components in isolation.
2. **Integration Testing**: Testing how components work together.
3. **System Testing**: Testing the entire system against requirements.
4. **Acceptance Testing**: Validating the system meets business needs.
5. **Regression Testing**: Re-running tests after changes to ensure existing functionality isn’t broken.
